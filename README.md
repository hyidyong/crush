# Unsent

개인용 Pygame DM 시뮬레이터입니다. 다크 모드 메시지, 가상 인물 프로필, 게시물, 사용자 전용 AI 봇을 제공합니다. 실제 소셜 계정에 연결하지 않습니다.

```bash
uv sync --locked --all-extras
UV_CACHE_DIR=.local/uv-cache uv run python tools/launch_local.py --open
```

브라우저에서 http://127.0.0.1:8765 를 엽니다. 네이티브 Pygame 창은 별도 터미널에서 `uv run python -m unsent`로 실행합니다. Enter는 메시지 전송, Shift+Enter는 줄바꿈입니다. 봇 편집기의 성격·예시 입력에서는 Enter가 줄바꿈입니다.

AI 서버를 설정하지 않은 공개 소스는 연결되지 않은 상태로 시작하며, 미리 작성한 문장으로 AI 답장을 대체하지 않습니다. 로컬 모델 설치와 개인 설정은 [실행 안내](docs/private-instances.md)를 참고하세요.

DM 작성 버튼 → 내 봇 만들기·관리에서 이름·소개·성격·대화 예시를 편집하거나 UTF-8 TXT/MD 파일을 가져올 수 있습니다. 모델 재훈련이 아닌 편집 가능한 참고 설정이며 실제 인물의 신원·감정을 재현한다고 보장하지 않습니다.

원본 파일·초안·프로필·수정 기록은 개인 기기 저장 공간에 귀속됩니다. 대화할 때는 현재 봇의 제한된 성격·예시만 선택한 AI 서버에 전달합니다. 공개 목록이나 서버 파일에 개인 봇을 등록하지 않습니다. 외부 AI 서버를 직접 설정하면 해당 운영자가 현재 대화와 활성 설정을 처리합니다.

기기 저장은 기본으로 꺼져 있으며 봇 프로필과 편집 초안은 별도로 보관됩니다. 공유 브라우저를 넘길 때는 설정의 새 비공개 세션을 사용하거나 브라우저/OS 프로필을 분리하세요. API 키·개인 데이터는 소스와 웹 패키지에 포함하지 않습니다.
